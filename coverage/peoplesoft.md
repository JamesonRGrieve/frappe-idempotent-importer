# Coverage: PeopleSoft → ERPNext

**Status: listed, not built.** Connections to PeopleSoft can be created, but they refuse to run ("The
PeopleSoft adapter is not built yet"). A later phase builds it on the shared engine: the same identities,
change hashes, writers, lockout safety and retirement as every built source.

- **Source API:** PeopleSoft's Integration Broker REST services.
- **Planned first-party homes:** HRMS Employees, Departments and Designations, Leave Applications, and Attendance.
- **Gaps:** recorded here, object by object, when the adapter is built: anything without a first-party
  home is listed as a gap, never approximated.
