# Coverage: Agendrix → ERPNext

**Status: listed, not built.** Connections to Agendrix can be created, but they refuse to run ("The
Agendrix adapter is not built yet"). A later phase builds it on the shared engine: the same identities,
change hashes, writers, lockout safety and retirement as every built source.

- **Source API:** A scraper of the manager's web views, run with the account's own login (as the importer's spec, Deck card 386, plans it).
- **Planned first-party homes:** HRMS Employees, Shift Types and Shift Assignments, Employee Checkins / Attendance, and Leave Applications.
- **Gaps:** recorded here, object by object, when the adapter is built: anything without a first-party
  home is listed as a gap, never approximated.
