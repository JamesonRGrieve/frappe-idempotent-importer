# Shopify GraphQL documents

Ported from [wp-woo-idempotent-importer](https://github.com/JamesonRGrieve/wp-woo-idempotent-importer)
(`graphql/fragments` and `graphql/operations`, commit 9c462e9, 2026-10-16): the fragments of the kinds this
adapter reads and the hand-written operations it sends, copied in so the two projects share no code.
Nested connections that are paged through take their page size from a variable (`$<field>First`) so the
client can shrink it when Shopify refuses a query as too costly. The list, by-id and nested-page operations
around the fragments are generated by `queries.QueryLibrary`. Every operation is validated against
Shopify's Admin schema for the pinned API version, and priced against a live store's charges
(`python -m tools.prove`).
